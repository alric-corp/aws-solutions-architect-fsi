# Conhecimento técnico

Trilha de estudo técnico, das peças isoladas à defesa em entrevista.

## Duas formas de estudar

**Percurso guiado — para construir entendimento.** A trilha [System Design a partir do zero](02-system-design/00-system-design-from-zero.md) acompanha uma loja fictícia e apresenta cada conceito quando ele é necessário. Comece pela [Aula 1 — Você clicou em um produto. O que aconteceu?](02-system-design/ecommerce/01-from-click-to-catalog.md). Não é preciso estudar os fundamentos antes: as aulas indicam o módulo correspondente quando vale aprofundar.

**Módulos — para aprofundar ou consultar.** Os fundamentos (F00–F12) e os módulos de System Design (SD01–SD05) tratam cada tema em detalhe. Use-os para aprofundar um conceito, revisar antes da entrevista ou consultar um assunto específico. Eles seguem a progressão abaixo.

## Progressão dos módulos

```text
Fundamentals
    ↓
System Design
    ↓
Cases FSI
    ↓
Mock Interviews
```

| Etapa | Objetivo | Onde |
|---|---|---|
| Fundamentals (F00–F12) | Entender as peças: o que cada tecnologia é e como funciona | [fundamentals](01-fundamentals/README.md) |
| System Design (SD01–SD05) | Combinar as peças e discutir trade-offs | [system-design](02-system-design/README.md) |
| Cases FSI (FSI01–FSI10) | Aplicar os dois níveis a problemas do setor financeiro | [cases](../cases/) |
| Mock interviews | Defender decisões e reagir a follow-ups | [interview/simulations](../interview/simulations/) |

Os IDs servem de referência rápida: F06 é um fundamento, SD03 um padrão de system design, FSI03 um case financeiro e STAR03 uma experiência comportamental.
