# Template — Extração de insumos de preparação

Use este registro em branco para separar uma recomendação recebida, a evidência que a sustenta e sua aplicação prática. Guarde anotações preenchidas e material pessoal em área privada; não publique transcrições, avaliações individuais ou dados internos.

## Origem verificável

- Autor ou organização:
- Link ou identificador privado do arquivo:
- Data de publicação, se disponível:
- Data da consulta:
- Trecho ou timestamp disponível:
- Insumo efetivamente lido: original / transcrição completa / trecho / resumo automático.
- Lacunas: trecho ausente, timestamp vazio, falante incerto ou contexto não recuperado.

Não complete uma lacuna como se estivesse no áudio. Se só houver resumo, registre essa limitação.

## Exemplo de classificação — ilustrativo

“Responder em até um minuto” pode ser um conselho de coaching útil para treinar síntese. Seu limite é eliminar decisões e evidências importantes de uma resposta complexa. Uma aplicação é ensaiar uma versão breve, sem impor esse tempo a toda pergunta. Esta é uma classificação didática, não uma citação atribuída a uma fonte específica.
